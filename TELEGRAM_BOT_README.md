# Telegram Bot Setup - Mentoria Hub

## Как создать бота:

1. Открой Telegram и найди **@BotFather**
2. Отправь команду `/newbot`
3. Введи имя бота: `Mentoria Hub Bot`
4. Введи username: `mentoria_hub_bot` (или любой доступный)
5. Получишь токен типа: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`

## Как запустить бота:

### Вариант 1: С дефолтным токеном (уже в коде)
```bash
npm run bot
```

### Вариант 2: Со своим токеном
1. Создай файл `.env.local` в корне проекта:
```
TELEGRAM_BOT_TOKEN=твой_токен_здесь
```

2. Запусти бота:
```bash
npm run bot
```

## Как пользоваться:

1. Запусти бота: `npm run bot`
2. Открой Telegram и найди своего бота
3. Отправь `/start` для получения кода привязки
4. Зайди на платформу → Дашборд → "Настроить Telegram"
5. Введи полученный код
6. Готово! Теперь будешь получать уведомления

## Команды бота:

- `/start` - Получить код привязки аккаунта
- `/help` - Список всех команд
- `/status` - Проверить статус привязки
- `/info` - Информация о боте

## Уведомления:

После привязки аккаунта будешь получать уведомления о:
- 📚 Новых курсах на платформе
- 🏆 Новых возможностях (стипендии, конкурсы)
- 📊 Изменениях в рейтинге
- 💬 Сообщениях от менторов

## Деплой на продакшн:

Для постоянной работы бота на сервере можно использовать:
- PM2: `pm2 start telegram-bot.js --name mentoria-bot`
- Systemd service
- Docker container
- Или запускать на отдельном VPS

## Заметки:

- Бот работает в режиме polling (опрашивает Telegram API)
- Для webhook режима нужен SSL сертификат и публичный URL
- В коде уже есть дефолтный токен для тестирования
- Можно запускать бота локально или на сервере
